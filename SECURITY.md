# Security

Report a security vulnerability in Wren privately, never as a public issue.

Report it on [this repository's Security tab](https://github.com/MultiboxLabs/wren-runtime/security/advisories/new). Say which release it affects, how to make it happen, and what it lets an attacker do. Multibox Labs replies there, and publishes an advisory once a fixed release is out.

Only the latest release gets fixes.

A vulnerability in Chromium itself, which Wren also has, goes to [Chromium's tracker](https://www.chromium.org/Home/chromium-security/reporting-security-bugs/). Wren takes Chromium's fix in its next release. Tell us about it too, if it is serious.
